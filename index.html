Install

How to install

No code, no special software — just your browser and about a minute of your time.

Install in Chrome

Also works in Edge, Brave, and Opera.

  1. 1

    Unzip the downloaded file.

    Double-click chrome.zip — your computer opens it into a folder.

  2. 2

    Open chrome://extensions in your Chrome browser.

    Type it into the address bar and press Enter.

  3. 3

    Turn on "Developer mode" — the switch at the top right.

  4. 4

    Click "Load unpacked".

  5. 5

    Select the unzipped folder (the one that contains manifest.json).

Install in Firefox

Loaded as a temporary add-on.

  1. 1

    Unzip the downloaded file.

  2. 2

    Open about:debugging in your Firefox browser.

    Type it into the address bar and press Enter.

  3. 3

    Click "This Firefox".

  4. 4

    Click "Load Temporary Add-on".

  5. 5

    Select the manifest.json file inside the unzipped folder.

A note for Firefox users: Firefox removes temporary add-ons when it closes. After a browser restart, simply open about:debugging again and re-select the same manifest.json file — it takes about 20 seconds.

How to use

Download a whole newspaper in four steps

If you can use a browser, you can use this. There is nothing to configure.

1

Open the archive

Go to the Reveal Digital archive you have access to and log in in that browser tab.

2

Click the extension icon

It lives in the toolbar at the top right of your browser. Pin it so it's always one click away.

3

Pick what to download

This issue, This newspaper, or Everything — the panel shows what each one means.

4

Click Start

That's it. Every page is saved as a PDF, and you can close the tab any time.

What you end up with

Every page becomes its own PDF, filed inside your browser's Downloads folder — one tidy folder per issue, named exactly the way the archive names it.

  • One folder per issue, e.g. 1922-Oct-01, Vol-01 Iss-01
  • One PDF per page, e.g. page01.pdf, page02.pdf…
  • Already-saved pages are skipped, so re-running is always safe.

FAQ

Questions? Good — here are the answers

The short version of everything people usually ask about.

Do I need to be logged in?

Yes. Open the archive in your browser and log in first — the extension works with the account you already have. No password is ever stored.

Why do some issues say “login required”?

Those pages are locked behind the archive’s subscription. The extension skips them and carries on with the rest — everything else downloads normally.

I closed my browser halfway through. Do I start over?

No. Just run it again — it checks what’s already saved and skips it, so it picks up right where it left off.

Where do the files go?

Your browser’s Downloads folder. You get one tidy folder per issue, named like the archive’s own labels, and inside it every page as page01.pdf, page02.pdf, and so on.

Is this really free?

Yes — the extension is free and open source. You can read the code, and even build it yourself, on GitHub.
